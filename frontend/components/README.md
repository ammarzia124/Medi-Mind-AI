# MediMind AI Components

Reusable UI components for the MediMind AI frontend.

## Component Categories

### Layout
- `Header` - Main navigation header
- `Footer` - Footer with disclaimers
- `BottomNav` - Mobile bottom navigation
- `PageLayout` - Common page layout wrapper

### UI Elements
- `Button` - Styled button variants
- `Card` - Content card component
- `Input` - Text input with validation
- `Textarea` - Multi-line text input
- `Badge` - Status badges
- `Modal` - Modal dialog

### Health-Specific
- `SeverityBadge` - Severity level indicator
- `CareNavigationBanner` - Care recommendation banner
- `LabResultCard` - Lab result display
- `TimelineCard` - Timeline entry card
- `Disclaimer` - Medical disclaimer component
