# MediMind AI - Public Assets

Static public assets for the MediMind AI application.

## Structure

```
public/
├── images/         # Image assets
├── icons/          # App icons and favicons
├── fonts/          # Custom font files
└── locales/        # Translation files (if needed)
```

## Usage

Files in this directory are served as-is and can be referenced directly in the application.

Example:
```html
<img src="/images/logo.png" alt="MediMind AI" />
```
